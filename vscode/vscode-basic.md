## Comandos basicos

- **[ Alt + q ]** Deshacer (ctrl + z)
- **[ Alt + W ]** Rehacer (ctrl + shift + z / ctrl + y )
- **[ Ctrl + g ]** abrir/cerrar barra lateral izquierda
- **[ Alt + g ]** abrir/cerrar barra lateral deracha
- **[ Ctrl + k ]** borrar linea desde el cursor
- **[ Ctrl + g ]** ir a linea:
- **[ Ctrl + t ]** abrir archivo en una pestaña nueva
- **[ Ctrl + Alt + w ]** Cerrar archivo actual
- **[ Ctrl + left ]** Avanzar por palabras hacia la izquierda
- **[ Ctrl + rigth ]** Avanzar por palabras hacia la derecha
- **[ Ctrl + p ]** Ir/ver a archivo
- **[ Ctrl + t ]** Buscar simbolo
- **[ Ctrl + Shift + P ]** barra de comandos

### Better Fountain (Piers Deseilligny)

### Bookmarks (Alessandreo Fragnani)

Extencion que permite colocar marcadores por lineas de codigo

- **[ Ctrl + Alt + < ]:** Colocar marcador
- **[ Ctrl + < ]:** Ir a la marca siguiente
- **[ Ctrl + Shift + m ]:** Borrar todos los marcadores
- **[ Ctrl + Alt + m ]:** Abrir book Marks

### Gemini Code assist (Coogle)

Asistente de codigo de Google gemini

- **[ Alt + a ]:** Ver asistente de gemini
- **[ Ctrl + Alt + a ]:** Aceptar cambios gemini
- **[ Alt + Shift + a ]:** Rechazar cambios gemini
