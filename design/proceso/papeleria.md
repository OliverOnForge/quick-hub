# Consejos Avanzados y Preparación de Arte Final para Papelería

## 1. Jerarquía de Tamaños de Texto

Es vital **respetar** los tamaños de texto en la maquetación. Las referencias de tamaño se dan tomando como base la tipografía **Helvetica**. Si usas una fuente diferente, compárala visualmente con Helvetica para asegurar una escala equivalente.

| Uso del Texto | Tamaño Recomendado (Puntos) | Notas |
| :--- | :--- | :--- |
| **Información Mercantil/Notas Legales** | **5 puntos** | El tamaño más pequeño, para información que debe estar, pero no destacar. |
| **Datos de Contacto (Párrafos)** | **7 a 9 puntos** | El cuerpo principal de información de contacto en tarjetas, sobres y hojas de carta. |
| **Elementos a Resaltar** | **10 puntos en adelante** | Utilizado para nombres propios en tarjetas de visita, titulares o cualquier elemento que deba tener prominencia. |

## 2. Flujo de Trabajo en Illustrator

El diseñador recomienda un flujo de trabajo altamente eficiente en software como Illustrator:

* **Documento Único:** Trabajar todos los elementos de papelería (**hoja de carta, sobres, tarjetas, carpetas**) en el **mismo documento** (mesas de trabajo separadas).
* **Uso de Símbolos (Crucial):** Utilizar la función **Símbolos** para el **isotipo** y la **información de contacto** que se repite. Esto permite **editar una vez** (ej., un número de teléfono) y que el cambio se aplique automáticamente en todos los elementos de papelería, ahorrando tiempo y evitando errores.
* **Troqueles y Medidas:** Para sobres o carpetas, la imprenta suele enviar el **trazado del troquel**; se debe diseñar sobre esta línea o medida exacta.
* **Tintas y Acabados:** Se recomienda definir en las muestras las **tintas planas (Pantone)** y otros acabados (ej. *Stamping* de color oro mate) para que la imprenta sepa exactamente qué procesos aplicar.

## 3. Preparación del Arte Final para Imprenta (PDF)

El arte final es la versión lista para imprimir. Aquí, la clave es la comunicación con la imprenta.

### Parámetros de Guardado (PDF)

| Configuración | Valor Recomendado | Propósito |
| :--- | :--- | :--- |
| **Sangrado (*Bleed*)** | **3 mm** | Área extra de diseño que se extiende más allá del borde de corte, esencial para evitar bordes blancos. |
| **Imágenes (Resolución)** | **350 ppi** (Píxeles por pulgada) | Se recomienda un mínimo de 300, pero 350 ppi asegura la máxima calidad de impresión. |
| **Compresión** | JPEG, Máxima | Para mantener la calidad visual de las imágenes. |
| **Marcas de Impresión** | Marcas de límite (o de corte) | Indicaciones para la imprenta sobre dónde cortar el papel. (Aunque inútiles en elementos troquelados como carpetas, se suelen incluir para las tarjetas y hojas). |
| **Conversión de Color** | **Sin conversión** | Si ya te has asegurado de que **todas las imágenes estén en CMYK** (y guardadas como TIFF, si aplica), puedes evitar la conversión para mantener el control. Si no estás seguro, usar "Convertir a destino (conservar valores)" pasa el RGB a CMYK. |
| **Tipografía** | **Convertir textos a contornos** | **Paso final y crucial** antes de guardar el PDF. Esto convierte el texto editable en formas vectoriales, asegurando que la imprenta no tenga problemas de fuentes faltantes. |

### Notas sobre las Mesas de Trabajo

* **Elementos Rectangulares (Tarjeta, Hoja de Carta):** La mesa de trabajo debe ser el **tamaño final** del objeto. La sangre se añade **automáticamente hacia afuera** de la mesa de trabajo al guardar el PDF.
* **Elementos Troquelados (Sobres, Carpetas):** La mesa de trabajo debe incluir el diseño **y su sangrado completo** ya que el troquel (la forma de corte) es irregular y no rectangular.

## 4. Presentación de la Papelería (*Portfolio*)

* **Método Preferido:** Lo más profesional y creíble es **imprimir físicamente** los elementos (aunque sean unas pocas copias) y hacerles una **fotografía de alta calidad** (*mockup* real) sobre un fondo adecuado.
* **Alternativa:** Si la fotografía no es posible, un **montaje digital (*mockup* en Photoshop)** sigue siendo una presentación igualmente válida.
