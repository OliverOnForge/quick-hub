
# Niveles de programacion en python

Lista de habilidades por nivel.

---

## Nivel Basico

- Imprimir 'Hola Mundo'
- Variables
- Tipos basicos de datos (int, float, complex, string, boolean)
- Operadores (aritmeticos, relacionales, logicos)
- Condicionales (if, else, elif)
- Ciclos (for, while)
- Colecciones de datos (Listas, tuplas, conjuntos)
- Uso de bibliotecas, modulos y paquetes
- Funciones
- Diccionarios
- Manejo de errores (try, catch, finaly)
- Manejo basico de Logs (logging)
- Manejo de archivos (open, read, write, close)
- Manejo de excepciones (raise, assert)
- Creacion de modulos y librerias.
- Principios de la Programacion orientada a objetos (POO)
- Aplicaion de POO a problemas de codigo y software
- Herencia usando super()
- Polimorfismo aplicando modificacion y sobreescritura de metodos
- Encapsulamiento usando public y private
- Herencia multiple (es un)
- Compositores (tiene un)

F-strings: El manejo moderno de cadenas (f"texto {variable}") es esencial hoy en día.

Entornos Virtuales: Aunque lo mencionas en el nivel medio, el uso de venv o conda se considera hoy una habilidad de supervivencia básica para no romper la instalación global de Python.

Pep 8 (Introducción): No es necesario dominarlo, pero conocer que existe una guía de estilo desde el inicio evita vicios de programación.

---

## Nivel Medio

- Desarrollo de software baseado en POO
- Bibliotecas estandar (pandas, json, numpy, matplotlib, os, sys, re, etc.)
- Control de versiones (git, github)
- PEP8
- Estructura de proyectos
- Contenedores (Doker)
- Consumo de APIs
- Tipos de datos como objetos en python (Listas, Tuplas, Diccionarios, Conjuntos)
- Comprensión de listas y expresiones generadoras
- Colecciones: iteración eficiente y optimización de bucles.
- Decoradores de funcion @
- @staticmethod y @classmethod
- Dunder methods (magic methods)
- Metodos de clases constructoras super() aplicada a clases y objetos superiores
- Interfaces, Contratos y plantillas (clases abstractas)
- kwargs y args
- Creacion de APIs (Flask, Django, FastAPI)
- Patrones de diseño (decorador y singleton)
- Implementacion de Try, ecept, else, finally
- Implementacion de Logs
- Pruebas unitarias y depuracion
- Patrones de diseño (factory, compositor)
- clases virtuales y modulos
- Inyeccion de dependencias
- Patrones de diseño (Bridge, Bilder y Prototipe)
- Entornos virtuales (venv)
- Programacion funcional basica (map, filter, reduce)
- Concurrencia basica(multithreading)
- Paralelismo basico (multiprocessing)

Type Hinting: El uso del módulo typing para definir tipos de datos es estándar en proyectos profesionales modernos para mejorar la legibilidad y el soporte de los IDE.

Gestores de Contexto: El uso de la sentencia with (context managers) tanto para archivos como para conexiones a bases de datos.

Pruebas con Pytest: Mientras que unittest es la biblioteca estándar, pytest es el estándar de la industria por su simplicidad y potencia.

Manejo de Dependencias: Uso de herramientas como pip, poetry o pipenv y la gestión de archivos requirements.txt.

Bases de Datos: Uso básico de SQLite o un ORM como SQLAlchemy para persistencia de datos.

--

## Nivel Avanzado

- Programacion asincrona (asyncio)
- Programacion orientada a eventos

Metaprogramación: Uso de metacases, introspección y creación dinámica de clases.

Internals de Python: Comprensión del GIL (Global Interpreter Lock), gestión de memoria y cómo funciona el recolector de basura (Garbage Collector).

Profiling y Optimización: Uso de herramientas para medir el rendimiento del código (cProfile, timeit) y técnicas de optimización de memoria (uso de __slots__).

Seguridad: Prácticas de codificación segura (prevención de inyecciones, manejo de secretos y variables de entorno).

Despliegue (CI/CD): Conocimiento de pipelines para automatizar pruebas y despliegues de aplicaciones Python.
